# Upwork Portfolio: Solize Solar Analyzer

---

### **Title**
**Solize – Standalone Desktop App for Solar Plant Performance Analytics & Automated Report Generation**

---

### **My Role**
**Full-Stack Software Engineer & Desktop App Architect**

---

### **Project Description**
* **Goal**: Automate complex daily solar plant analytics by converting manual Excel logs (inverter & weather logs) into an offline-first Windows desktop application.
* **Solution**: Developed a high-performance FastAPI/Pandas backend to compute plant KPIs (PR, degradation) and paired it with a modern React frontend wrapped in a native PyWebView desktop window.
* **Impact**: Reduced monthly reporting time from hours to a single click, automatically generating executive PDF/Word reports. Delivered a zero-dependency installer wizard.

---

### **Skills**
React | TypeScript | FastAPI | Python | SQLite | Pandas | PyWebView | Inno Setup | Document Automation (ReportLab, python-docx)

---

### **Deliverables**
* **Standalone Executable (`.exe`)**: Desktop application binary compiled with a hidden command prompt.
* **Professional Installer (`Setup.exe`)**: An Inno Setup installation wizard for direct client distribution.
* **FastAPI Backend & React Frontend Code**: Completely functional web-stack integrated into the desktop build.
* **Automated PDF & DOCX Export Engine**: Clean report templates showing plant analytics, charts, and recommendations.
