**Full-Stack Software Engineer & Desktop App Architect** | *[Insert Date]*

#### **Technologies Used**
React, TypeScript, FastAPI (Python), SQLite, Pandas, PyWebView, Inno Setup, ReportLab, python-docx

* **Automated Document Generation**: Programmed a custom template generation engine to export executive-ready PDF (ReportLab) and Word summaries (python-docx) with automated charts and performance recommendations.
* **Installer Compilation**: Scripted and built a professional installation wizard using Inno Setup for simple, plug-and-play distribution.
* **Business Impact**: Eliminated manual Excel data cleaning and analysis, reducing monthly client reporting overhead from hours of manual work to a 5-second automated download.
